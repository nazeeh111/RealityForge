THE METHOD

A prediction should
come with evidence.

RealityForge tracks a moving object in a fixed-camera recording, identifies a supported planar motion family and uses a compact neural estimator to initialize physics-based parameter refinement.

The first part of the recording estimates the model. The remaining frames test its prediction. Change a parameter to run a counterfactual using the same initial conditions.

Know the boundary

Perspective, unknown scale, occlusion and the wrong physical model can make parameters ambiguous. Pixel measurements are not metric measurements. Confidence intervals do not account for every source of error.

Supported models: a damped planar pendulum and straight-line constant-acceleration sliding. Collisions, deformable objects and general 3D reconstruction are outside the validated scope.
